# SI Grid Monitor V1.0.6.1 implementation status

Status: **draft hotfix; local automated validation passed, real Home Assistant
acceptance pending**.

## Implemented

- Responsive Source Health metric cards for Android, tablet and desktop.
- Separate full-range counts for observed source interruptions and integration
  lifecycle transitions while preserving schema-8 raw events and reason codes.
- Second-precision Europe/Ljubljana incident timestamps, human-readable display
  durations and explicit ongoing/completed/restart-unknown status labels.
- First-recorded diagnostic timestamp so earlier periods remain unknown rather
  than being implied healthy.
- A labelled, selectable timeline with unknown background, three date/time axis
  points and distinct healthy, unavailable, stale, invalid and lifecycle styles.
- Restart-unknown records retain their exact timestamps in incident detail but
  render as an observed-state marker plus an explicitly hatched uncertainty
  span, never as confirmed state coverage through the restart gap.
- Structured historical contract evidence cards retaining all configuration
  epochs, dated assignments, B1–B5 limits, provenance and technical details.

## Safety and compatibility

- SQLite remains schema 8; no migration or historical rewrite is introduced.
- Billing, sustained forecasts, publishing cadence, source identities, entity
  IDs, quarter coverage and contract evidence are unchanged.
- Lifecycle events no longer inflate source-interruption or affected-quarter
  metrics, but remain queryable and visible as their original raw records.
