## Data safety

- Schema 6 adds `reconstruction_jobs`, `quarter_revisions`, `archive_backups`
  and history query indexes. Existing `quarters`, `source_epochs` and checkpoints
  are not rebuilt.
- Audit-only does not change quarter rows. Applying a plan uses the same quality
  ranking as startup backfill and cannot replace stronger evidence.
- A confirmed operation creates a SQLite online backup before the first quarter
  update. If Home Assistant stops mid-job, completed rows and the backup remain
  valid and the job is marked partial/failure when the exception is observed.
- Backup restore is deliberately not automated in the dashboard. Restore should
  be performed only while the integration/database is closed and after preserving
  the current database and WAL files.

## Required real Home Assistant validation

The automated suite cannot establish Android rendering, Recorder behavior with a
production database, disk-full behavior, or end-to-end HACS installation. Follow
`MANUAL_TEST_PLAN.md` before release approval. Do not treat this document as a
claim that the release has passed real Home Assistant acceptance.
