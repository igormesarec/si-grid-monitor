# SI Grid Monitor V1.0.5 implementation status

## Scope

V1.0.5 is a focused release candidate for cross-quarter live-chart smoothing
and safety-margin clarity. It does not change the forecast formulas, fixed
quarter energy accounting, tariff rules, source freshness, publishing profiles,
entity identities, contract history, or SQLite schema 7.

## Implemented

- The authenticated live payload keeps `trace` current-quarter-only and adds a
  separate `smoothing_context` containing the configured pre-quarter window and
  only a still-valid predecessor sample when required by time weighting.
- The frontend evaluates the solid historical smoothing path from that context,
  clips its visible output at the current quarter start, and keeps actual power
  paths on the existing quarter-only trace.
- Future assumptions still begin at the backend generation timestamp and end at
  the quarter boundary. A detached anchor remains only when displayed evidence
  cannot support the backend value.
- Python and JavaScript share deterministic parity fixtures. Both use
  piecewise-constant samples, a 60-second validity cap, `[start, end)` windows,
  import-only conversion, explicit coverage, and a 1 ns completeness tolerance.
- A known contract with 0.000 kW margin is identified as having no additional
  safety margin; a missing contract remains unavailable.

## Automated evidence

Focused engine, runtime, frontend and localization tests cover all supported
smoothing windows, irregular updates, import/export reversals, zero import,
stale gaps, exact rollover clipping, forecast anchoring, and safety-margin
states. Full repository validation results are recorded in the pull request.

## Manual acceptance still required

Real Home Assistant and Android Companion validation is pending. Follow the
V1.0.5 items in `MANUAL_TEST_PLAN.md`, including two-meter rollover behavior,
restart recovery, mobile widths, both themes/languages, stale-gap recovery, and
