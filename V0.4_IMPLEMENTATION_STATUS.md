## V0.4.1 hotfix status

- Historical quarter and Today APIs now convert genuine schema-5
  `sqlite3.Row` results through their column keys. Populated, empty and
  incomplete archives are JSON-serialization tested.
- Backend failures produce privacy-safe WebSocket error codes while Home
  Assistant logs retain operation, entry, request and traceback diagnostics.
- Frontend errors are distinct from successful no-record results and offer an
  explicit retry instead of leaving Today in a loading state.
- Tariff Calendar shows the localized weekday and updates hour details without
  rebuilding the timeline; scroll position, highlight and keyboard selection
  are retained on normal and DST-length days.
- Overview adds one-kW power support lines and a separate cumulative
  import-only quarter-energy view. These are visualization changes only and do
  not alter the import-only engine or archive.
- The live kW view now uses the engine's complete smoothed import window as its
  future persistence assumption from the forecast anchor to the fixed-quarter
  end. It is dashed and separate from both measured smoothing and the projected
  final quarter-average demand. The solid trace uses the same time-weighted,
  stale-limited integration as the Python engine and reaches that anchor only
  when the configured window has genuine coverage.
- The kWh view treats runtime `quarter.import_kwh` as authoritative. It draws a
  detailed cumulative trajectory only when the bounded trace has continuous
  stale-limit coverage and reconciles within 0.001 kWh; otherwise it shows the
  current authoritative point and an explicit gap/inconsistency explanation.
- Verified contractual limit, contractual safety-margin reference, simulation
  threshold and actual engine operational target are distinct. With 3.50 kW,
  0.20 kW and a 2.50 kW simulation threshold, the engine line is 2.30 kW.
  Unknown/provisional contracts do not produce a confirmed contractual line.
- A mathematically inconsistent projected final energy is retained only as an
  internal diagnostic. Its chart line and user-facing values are unavailable
  with an explicit explanation.
- Mobile charts use wrapping legends outside the plot, local time endpoints and
  explicit kW/kWh axis titles so clustered references do not overlap. The SVGs
  retain their readable native 1120-pixel drawing width and scroll inside their cards rather
  than shrinking text or overflowing the whole panel.
- Chart endpoints include Ljubljana GMT offsets. After a quarter rollover, a
  backend smoothing value without sufficient current-trace history is rendered
  as a detached forecast anchor, never as fabricated measured continuity.
- SQLite remains schema 5. No migration, recalculation, row rewrite, contract
  reset or configuration-epoch change is introduced by this hotfix.

Budget headroom is not physical breaker, phase, wiring, connection or inverter
capacity. V0.4 does not control loads.

## PR #5 review corrections

- Setup and Options: translated `data_description` now provides field-by-field explanations for every input, in addition to step summaries (English and Slovenian).
- TODAY chart: a shared kW scale places import-only demand above a fixed zero line, average export below it, and immutable quarter targets on a stepped line. It distinguishes measured zero, missing, incomplete, provisional, live and confirmed data.
- TODAY data: the in-progress quarter is overlaid from runtime measurements and its projection is never counted as a completed result. Future current-day intervals are UPCOMING. Block summaries use the same archive validity classifier as daily totals, exclude simulations from genuine statistics and keep partial observations separate.
- Multiple meters: changing entry clears live, historical, Today, calendar and transition state; entry/generation tokens reject delayed responses from the previous meter.
- Archive navigation: Previous/Next use exact UTC 15-minute steps, repeated local times include their UTC offsets, future archive navigation is blocked, and summary-only records never fabricate traces.
- TARIFF CALENDAR: selectable hourly cells display block, effective kW target, rule verification, holiday, timezone offset and DST fold.
- Upcoming lower-limit panel: separates horizon-wide sustained reduction from an informational future contract change; reports unavailable forecasts honestly rather than attributing a reduction to the next block without evidence.
- Python view-model and Node behavioral tests cover archive reconciliation, live-quarter rollover, DST day lengths, graph geometry, missing versus measured zero, navigation and stale multi-meter responses. Real HA/HACS visual and interaction validation remains required. SQLite stays at schema 5 and no source epoch or historical row is rewritten.
