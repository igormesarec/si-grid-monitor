# SI Grid Monitor V0.6.0 implementation status

V0.6.0 combines the originally planned V0.5 PERIOD/BLOCKS milestone and V0.6
EXCEEDANCES milestone. The MASTER `SPECIFICATION.md` remains unchanged.

| Area | Status | Evidence / limitation |
|---|---|---|
| Shared period boundaries | Implemented | Ljubljana calendar semantics, UTC half-open ranges, DST/leap/ISO tests |
| SQL period aggregation | Implemented | Schema 5, namespaced bounded queries, shared validity predicates |
| PERIOD dashboard | Implemented | Six period types, four chart modes, comparison and drill-down |
| BLOCKS dashboard | Implemented | Always B1-B5, stored targets, reconciliation and peak details |
| EXCEEDANCES dashboard | Implemented | Confirmed-only rows, safe sort/filter and server pagination |
| Data-quality separation | Implemented | Valid, eligible, incomplete, missing, simulation and provisional remain distinct |
| Historical provenance | Preserved | Reports read immutable row values; no recalculation or rewrite |
| SQLite compatibility | Preserved | Schema remains 5; no migration is introduced |
| V0.4.2 live behavior | Preserved | Calculation engine, entities and source modes are unchanged |
| Automated validation | Required before PR handoff | pytest, Node tests, Ruff, compileall, hassfest, HACS and Actions |
| Real HA/Android acceptance | Not yet verified | Follow `MANUAL_TEST_PLAN.md` on the user's installation |

Known limitations:

- Reports cannot reconstruct dates before the independent archive began.
- Quarter records contain summaries, so historical detail never fabricates a
  second-by-second power trace.
- Excess-energy equivalent is analytical only, not an official billed fee.
- The dedicated HISTORY explorer/export milestone remains V0.7 scope.

No new index or migration is required: schema 5 already indexes namespace/end,
namespace/demand, namespace/block and namespace/exceedance access paths.
The new APIs aggregate in SQLite and return bounded calendar bins or pages rather
than loading a multi-year archive into the browser.
