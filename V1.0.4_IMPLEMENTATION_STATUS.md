# V1.0.4 implementation status

## Scope

Focused Home Assistant statistics compatibility and safe legacy-repair guidance.
No calculation, source-mode, contract, tariff, entity-identity or archive-schema
change is included.

## Implemented

- Preserved current-quarter import/export energy as live `kWh` values without a
  state class.
- Preserved stable description keys and per-entry unique IDs.
- Added a regression proving the coalesced public series can omit the exact
  final value before a quarter reset even though the archive is exact.
- Added a guard preventing integration code from directly addressing Home
  Assistant statistics storage tables.
- Documented backup-first native Statistics-tool review and explicit deletion.
- Audited V0.9–V1.0.3 metadata and classified current power statistics separately
  from obsolete current-quarter energy statistics.
- Updated version and frontend cache keys to V1.0.4.

## Deliberately not implemented

- No automatic statistics deletion, acknowledgement or direct Recorder SQL.
- No custom duplicate RepairsFlow.
- No state-class restoration and no lifetime-energy entity.
- No schema-7 migration and no historical-row rewrite.
- No Recorder/InfluxDB configuration changes.

## Acceptance status

- Python: 402 tests collected, full suite passed with 8 environment-dependent
  skips already declared by the suite.
- Frontend model/panel: 100/100 passed.
- Playwright rendered layout: 27/27 passed.
- Ruff, compileall, JavaScript/JSON syntax, diff hygiene, hassfest, HACS and
  GitHub Actions: recorded in the final delivery report after completion.
- Backed-up Home Assistant repair workflow: pending manual acceptance.
- Physical Recorder/InfluxDB storage: remains a manual measurement gate.
- Production readiness: conditional on the manual Home Assistant procedure.

## Storage benchmark

The unchanged two-meter benchmark produced 935,292,883 bytes/year on the
23-hour DST day, 918,653,200 on the normal day, and 936,489,728 on the 25-hour
DST day. V1.0.4 adds no entity publication and therefore no new event volume.
