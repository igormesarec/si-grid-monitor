Mode D deliberately does not claim verified instantaneous or sustained forecasts.
Bidirectional net deltas remain contractually unconfirmed because they can hide
import/export reversals. Separate counter channels keep independent baselines and
are joined only over overlapping evidenced intervals. Counter intervals crossing
fixed quarter boundaries are not promoted to confirmed contractual measurements
without allocation evidence.

Final acceptance regressions exercise both asynchronous channel update orders,
independent import and export resets, an unavailable export channel, reload with
fresh independent baselines, and a counter interval crossing a fixed-quarter
boundary. A dedicated legacy Mode A test restores a V0.9 checkpoint with the
unchanged signed-source identity; the config-flow duplicate guard continues to
use the legacy `signed:<entity_id>` key.

Local consolidated validation on Windows: 305 Python tests collected, 297 passed
and 8 real-event-loop tests skipped because the managed Windows runtime cannot
create `socketpair`; all 83 frontend behavioral tests passed. Ruff, formatting,
`compileall`, JavaScript syntax and translation JSON checks passed. The managed
Windows host cannot run the 16 rendered Playwright scenarios because its Chromium
binary is unavailable; GitHub Actions remains the authoritative rendered-layout
check. Real Home Assistant and Android Companion acceptance remains pending.

GitHub Actions on Linux is the authoritative check for the real-event-loop and
16 rendered Playwright scenarios, together with Ruff, `compileall`, JavaScript
syntax, hassfest and HACS validation. Real Home Assistant and Android Companion
